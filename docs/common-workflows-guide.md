# 常用工作流补齐

这四项在原有面板内提供，无需新增导航项或 Java 依赖。

## HTTP 请求集合与环境变量

1. 在账号密码工具里创建并解锁保险库，或在 HTTP 页点击“解锁保险库”。
2. 填写方法、URL、请求头和请求体，点击“保存请求”，输入名称，可勾选收藏。同名保存会确认覆盖。
3. 在“环境变量”里创建 dev/test/prod 等环境；变量名使用字母、数字、下划线、点或短横线，以字母或下划线开头。
4. URL 填 `{{baseUrl}}/api/users`，请求头填 `Authorization: Bearer {{token}}`。选中环境再发送；未定义变量直接报错，不发送请求。变量按原文替换，不自动进行 URL/JSON 转义。
5. “发送预览”隐藏标为敏感的变量；“历史”可载入最近 50 条请求或清空。记录的是原模板，不是替换后的 token。

整个集合、环境值及历史（包括手工粘贴在请求头/Body 的凭据）均存入加密保险库，未解锁时仍可发送普通请求，但不保存历史。锁定会清空集合和环境选项、请求/响应编辑区，并取消在途 HTTP 请求。环境编辑表会显示其值；“敏感”选项用于隐藏发送预览值。预览不能自动识别手工嵌入模板的秘密。

cURL 导出保留输入模板；不导出环境替换后的敏感值。集合暂未与 OpenAPI 页共享，也没有批量集合导入导出。

HTTP 页与 OpenAPI 页共用执行器，支持 PATCH、取消、完整响应超时 15 秒及 8 MiB 响应上限。重定向直接显示 3xx/Location，不自动跟随。JDK 管理的 Host、Content-Length 等受限请求头不能手动覆盖。SSH 隧道维持原有映射方式，HTTPS 域名校验限制没有在本轮重做。

## 数据库结果导出

执行查询后，在“执行结果”标题栏点击“导出结果”，可选 CSV、XLSX、JSON、SQL INSERT。

- 导出的是最近一次成功查询的内存快照，不会重新执行 SQL，也不会自动写回数据库。
- 原有查询默认最多加载 5000 行，超限仍有提示。导出窗口说明当前行数和截断情况；它不是全表备份工具。
- CSV 使用 UTF-8 BOM、CRLF 和双引号转义；未加引号的 `\N` 表示 NULL，空字符串为 `""`，二进制为 Base64。默认保护以 `= + - @` 开头的文本，导出前可关闭保护。
- JSON 保留数字、布尔与 NULL，日期为文本、二进制为 Base64。重复列名必须先用 SQL 别名区分，避免覆盖字段。
- Excel 把大于 15 位精度的数字写成文本，避免数值失真；不把内容当公式。单格超过 32767 字符会停止导出并保留原文件。
- SQL INSERT 需要指定目标表，可填 `schema.table`；支持标准、MySQL、PostgreSQL、SQL Server、Oracle 的标识符和二进制字面量。文本转义考虑 MySQL 反斜杠和 PostgreSQL E 字符串。生成文件仍应按目标表结构检查后执行。
- JDBC Blob/Clob 单值超过 1 MiB 会明确报错；可在查询中选取需要的片段。普通日期/时间保留 JDBC 提供的类型，不自动猜测字符串列。
- 输出先写临时文件，全部成功后替换目标文件；覆盖现有文件会先确认。

## TCP 长度字段分帧

TCP 客户端或服务端的分帧方式新增“长度字段”。配置字段偏移、宽度（1/2/4 字节）、大小端、头部总字节数及最大帧长。

- 长度值不包含头部：总帧长 = 长度值 + 头部字节数。
- 长度值包含头部：总帧长 = 长度值。
- 长度字段本身必须完全位于头部内。
- 可选择接收显示时去掉头部；统计和回显仍依据原始字节。
- 最大帧长默认 64 KiB，可调至 16 MiB。先读取长度字段并验证，再等待剩余数据；无效长度会关闭连接，不尝试猜测下一帧起点。
- 例如 `[00 03][61 62 63]`：偏移 0、宽度 2、大端、头部 2、不包含头部，得到五字节完整帧；勾选剥离头部后显示 `abc`。

UDP 仍按数据报显示。此功能只负责接收分帧，不自动为发送内容生成长度头。

## K8s 端口转发

1. 安装可访问目标集群的 kubectl，并把它放在 PATH，或在转发窗口填入可执行文件完整路径。
2. 在 K8s 管理面板连接集群，选择 Pod、Service 或 Deployment 行，点击资源卡片上的“端口转发”。也可以手工填写名称和命名空间。
3. 填目标数字端口或端口名。本地端口填 0 时由 kubectl 自动分配；成功后从会话列表复制 `127.0.0.1:端口`。
4. 可同时启动多个会话、查看各自最近 200 行日志并停止所选会话。关闭转发窗口、断开集群或退出应用会停止相关子进程。

仅监听 127.0.0.1，协议为 TCP。Service/Deployment 到 Pod 的选择和 Service 端口映射由 kubectl 处理；Pod 退出或 kubectl 失败时显示结束状态，不自动重试。

使用当前连接的 Server、Token、CA 和客户端证书/私钥生成仅当前用户可访问的临时 kubeconfig，凭据不进入进程参数；会话结束删除。关闭会话后子进程先正常终止，1 秒仍未退出则强制终止。30 秒没有建立监听会停止并提示。

需要相应的 Kubernetes RBAC 权限和与集群兼容的 kubectl。当前工具没有转交 kubeconfig exec 登录插件；使用的仍是面板已解析并解锁的 Token/客户端证书配置。

参考：[kubectl port-forward](https://kubernetes.io/docs/reference/kubectl/generated/kubectl_port-forward/)、[kubeconfig v1](https://kubernetes.io/docs/reference/config-api/kubeconfig.v1/)。
