# 功能检查与补齐（2026-09-29）

检查基于 `154951d`。本轮重点审阅 OpenAPI 调试、TCP 客户端连接生命周期和证书签发，不能据此认为全部工具均已完成审计。

## 已修复与补齐

| 范围 | 原问题 | 当前行为 |
|---|---|---|
| OpenAPI 请求 | 列出 PATCH 接口，但 HttpURLConnection 无法发送 PATCH | 使用 JDK HttpClient，支持 PATCH 和取消请求；超时覆盖响应体读取，最大缓冲 8 MiB |
| OpenAPI 参数 | 点发送或复制 cURL 时尚在编辑的单元格未提交 | 先提交编辑值；操作级参数按名称与位置覆盖路径级参数 |
| OpenAPI 示例 | 引号/换行未转义；嵌套对象内容丢失；自引用数组引发栈溢出 | 使用 JSON 节点生成示例，支持嵌套属性、默认值、枚举、本地引用；对递归深度和节点总数设限，循环处生成 null |
| OpenAPI cURL | 双引号下的感叹号转义改变内容，且 -d 的 @ 前缀可能被解释为本地文件 | 复用 POSIX 单引号引用，使用 --data-raw，补默认 Content-Type 并保留手工设置 |
| OpenAPI 响应 | 强制按 UTF-8 逐行读取，改变非 JSON 响应换行与编码 | 按 Content-Type 的字符集解码，保留原始文本换行；重定向显示状态码及 Location，不自动转发请求 |
| TCP 自动重连 | 首次连接失败直接关闭会话 | 开启自动重连后首次失败也重试，手动取消立即停止；未开启时保留原来的失败行为 |
| TCP 状态 | 读线程先启动，极快的 EOF 可能先于连接成功事件；失败返回也可能把面板标成已连接 | 先发布连接事件再启动读写，界面依据实际连接状态更新；忽略旧会话迟到的日志回调 |
| 证书签发 | 没有验证 CA 权限、有效期及私钥配对，可能导出不可用证书 | 签发前验证有效期、BasicConstraints、keyCertSign 和签名/验签配对；RSA、EC、SM2 与双证书均覆盖 |
| 证书有效期 | 接受非正年数，叶子期限可能超过 CA | 拒绝非法期限，叶子截止时间取请求期限与 CA 到期时间的较早者 |

证书检查没有验证 CA 是否被系统信任，也没有在线检查吊销；这里验证的是输入签发材料是否可用。叶子有效期上限是本工具的签发策略。

## 验证方法

- 新增回归测试先在旧实现上执行：11 个用例全部暴露问题，其中自引用数组为 StackOverflowError，带引号的属性为 JSON 解析错误。
- HTTP 用本机 HttpServer 验证 PATCH/POST/PUT/DELETE、错误响应、响应字符集、重定向、超大响应、超时和中断取消。
- TCP 用回环套接字验证首次失败重试、服务稍后启动、取消及线程回收。
- Swing 测试实际触发参数编辑、发送、取消与连接操作；未进行人工目视排版验收。
- 证书测试覆盖三种算法的私钥不配对、非 CA、过期/未生效、无签发权限、有效期上限和国密双证书。
- JDK 21.0.11 与 JDK 17.0.20.1 分别执行 `mvn -B -o verify` 均成功：每次 2332 个用例，0 失败、0 错误、1 跳过；包含新增的 29 个用例，依赖检查与打包通过。唯一跳过的是 Windows 缺少符号链接创建权限的测试。
- `git diff --check` 通过；未新增依赖，未人工验收窗口排版，未在 Linux 上运行本轮改动。

## 后续功能优先级

1. HTTP 请求集合与环境变量：减少反复粘贴 URL、请求头和 token，复用已有保险库。
2. CSV / Excel 生成 SQL：列映射、NULL/空串、日期/数值处理与 SQL 文件导出。
3. TCP 长度字段分帧：现有工具已有分隔符、定长和空闲超时，长度字段适用于常见二进制协议。

这些候选已登记路线图，尚未实现。Cron 的 Unix/Quartz/Spring 方言区分和视频监控真实播放器仍需要独立设计，未纳入本次修改。

## 核对依据

- [JDK 17 HttpRequest.Builder](https://docs.oracle.com/en/java/javase/17/docs/api/java.net.http/java/net/http/HttpRequest.Builder.html)：请求方法与请求体构造。

- [RFC 5280](https://www.rfc-editor.org/rfc/rfc5280.html)：CA 基本约束、密钥用法及证书有效期。
