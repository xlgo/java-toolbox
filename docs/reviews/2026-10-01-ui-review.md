# 常用工作流界面优化

基于已提交并推送的功能版本 `c5fbf47`，本轮集中优化 HTTP、TCP/UDP、查询导出和 K8s 转发四处界面，以及共享说明文字组件。

## 调整

- HTTP：集合和环境分行，选择器随宽度伸缩；低频操作收进“更多”，发送与取消保留在标题栏。增加 Ctrl+Enter；请求/响应区域可拖动分配高度。保险库锁定时禁用集合操作并提示原因。环境变量编辑器提供明确的行操作、名称标签和敏感值隐藏。
- TCP/UDP：连接/停止固定在顶部，发送固定在发送卡片标题栏。配置与发送区域支持纵向滚动；日志、发送区和快捷发送之间可拖动调宽调高。长度字段参数按标签/输入成组排列，无关的分隔符输入隐藏；日志的次要选项收进“更多”。
- 导出：按格式显示专属设置，CSV 才显示公式防护，SQL 才显示表名和方言；增加各格式的说明和文件类型过滤器。表名缺失时保留已填写设置，返回修正。
- K8s：配置/会话/日志分区，资源类型紧凑展示，资源名称获得更多输入宽度，增加 kubectl 文件选择入口。会话表格按列展示地址、目标和状态。无会话时有引导；按会话状态启用停止/复制。刷新仅更新发生变化的单元格和日志，保留选中会话、日志选区及阅读位置。
- 共享说明文字：修正 JLabel HTML 中 CSS 宽度未让文本换行的问题，直接为 HTML View 设置可用宽度，让说明高度随窗口宽度变化。

- 检查 HTTP 820×680、TCP 920×740、K8s 850×740、导出 560×415/435，以及约 700×560 的窄窗口。尺寸为渲染容器尺寸，不含主应用侧栏。
- 使用虚构请求与转发会话展示非空状态；渲染探针未发起网络连接或启动 kubectl。未进行人工生产服务操作。
- 新增三项自动化回归：说明文字窄/宽尺寸切换、K8s 刷新保留会话与日志选区、选择变化立即显示日志并更新按钮状态。
