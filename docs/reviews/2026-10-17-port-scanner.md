# 批量端口扫描第一批实现与验证（2026-10-17）

保留稳定工具 ID `port.scanner`，将原单目标端口扫描面板拆为目标/端口领域解析、扫描会话、TCP 探测和结果仓库。没有增加第三方运行时依赖，复用 JDK Socket、现有 SQLite JDBC、Jackson、UI 组件和配置分块存储。

## 已实现

- 多 IPv4、末段简写及完整 IP 范围、CIDR、域名和单 IPv6；区间去重、排除和展开前预算校验。默认 CIDR 排除常规首尾，/31、/32 保留全部。DNS 每域名每批解析一次，独立池和队列有界；预览不访问 DNS。
- 端口组与离散/范围表达式合并并排除，不静默忽略非法项。七组内置预设和用途提示共享资源；支持自定义组增删改、重命名及持久化。长端口文本复用分块偏好存储，避免 Preferences 的单值长度限制。
- 默认连接超时 500 ms、全局并发 64、单主机并发 8、提交速率 200/s。参数可设置；任务预算默认 4,096 主机、100 万次探测。扫描前解析最终 IP 并校验预算，禁止构造完整主机×端口任务列表。
- 有界任务池、主机轮转、配额限速和主动关闭 Socket 的停止流程。最多全局并发个在途任务，每批结果至多 500 条入库。停止后保留已接收结果，不为未执行任务生成关闭记录。
- 临时 SQLite 存完整结果，界面分批刷新、每页 500 条；主机汇总、状态筛选、文本搜索、复制开放端点、CSV/JSON 全量或筛选导出。CSV 文本字段保护公式，JSON 带完整任务参数；导出先写临时文件，成功后替换目标。
- 配置弹窗包含目标排除、端口组和高级参数，主页面保留输入、操作和结果。清空、启动新任务和回调通过会话代次隔离；应用退出关闭任务与本次结果缓存。

## 语义和真实连接验证

表达式回归确认 `192.168.1.10-20` 配 `22,80,443,8080-8082` 为 66 次；常规 /24 配 13 个端口为 3,302 次。覆盖重叠去重、排除、CIDR 首尾、跨网段范围、反向和非法输入、/0 在展开前超预算。

仅在本机回环测试，不扫描用户外部网段。实际 UI 输入 `127.0.0.1-2,::1` 和两个临时监听端口，完成 3 个主机×2 个端口=6 次探测，找到 2 个开放端点：IPv4 和 IPv6 各一个，其他连接失败。原目标、实际 IP、端口和协议均出现在表格。

回归另验证全局及单主机并发上限、公平轮转、设为单线程时严格串行、限速边界、域名去重与解析失败、排除域名失败不探测、停止主动关闭正在连接的 Socket、停止/重启隔离以及未启动会话的缓存清理。

仓库测试写入 1,200 行，验证 500/500/200 分页、开放过滤、按主机和 DNS 失败过滤、全量流式导出、IPv6 复制、CSV 公式保护及缓存上限失败不丢失旧结果。

## 构建与资源检查

- JDK 17 完整 `mvn -B -o verify`：2,547 项测试，失败 0、错误 0、跳过 1；打包和依赖声明分析通过。
- 定向回归首轮 28 项、补充 Socket 取消后 29 项均通过。最后的限速优化、长配置和布局修改另执行最终定向 verify：31 项全部通过，打包与依赖检查通过。
- 原面板 42 条硬编码中文全部迁入三份语言资源，国际化基线由 3,334 降到 3,292，没有抬高基线。
- 实际窗口在 1,240×820 和 960×720 检查，配置、端口组及高级参数弹窗可用；较窄窗口的主机列支持横向滚动和完整文本提示。最终 31 项复验产物的类、预设资源与三份语言资源校验一致，Java class 格式为 JDK 17。
- 独立可控探针基准：100 主机×100 端口，共 10,000 次，超时参数 500 ms、全局并发 64、单主机 8、速率配置 10,000/s；受控探针直接返回结果，不建立真实外部连接。Windows 逐任务等待初次耗时 99.26 秒，改为有界配额调度后 3.03 秒，含入库和 JSON 导出。样本中堆使用峰值约 24 MiB，SQLite 文件 1,110,016 字节；10,000 行导出完整，开放结果为设定的 1,000 条。这只验证调度和缓存开销，不代表外部网络速度。
- 补充正常 JVM 退出的仓库清理 hook，避免主窗口立即退出时尚未执行异步清理；正常关闭仓库会移除此 hook。该调整后的 21 项定向 verify 通过。DNS 失败的主机汇总区分“解析失败记录”和实际端口探测数，不将解析失败计为探测一次；最后仓库/会话/UI 的 14 项 verify 全部通过，独立 JVM 退出探针确认临时数据库被删除，最终 JAR 再次检查通过。

## 当前边界

IPv6 范围/CIDR、通配符、目标文件导入、命名扫描方案、TLS/HTTP 联动和快照对比留在第二批。当前不做 UDP 和服务 Banner 探测。连接失败保留系统原因，超时不称为关闭或确认被过滤。停止时在途结果可能来不及入库，导出以已保存记录为准；异常进程退出可能留下临时缓存文件。没有新增自动联网扫描行为。
