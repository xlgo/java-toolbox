# 启动器式主界面重构（new-ui）

日期：2026-10-28
分支：`new-ui`
范围：`com.aqishi.toolbox.ui` 壳层与主题层，工具面板实现未改动。

## 背景

原界面是「树形侧边导航 + 工具栏 + 内容区」：76 个工具全部展开在侧栏树里，需要滚动查找；
主题与语言是两个下拉框，占掉了工具栏的大半宽度。

本次按效果图改为启动器形态：侧栏只保留一级分类，工具以彩色磁贴铺在主区，
搜索、收藏与一键主题切换集中到顶栏。

## 交付范围

| 组件 | 职责 |
|---|---|
| `TopBar` | 返回、搜索（140ms 去抖、输入法组字保护）、收藏筛选、深浅一键切换、皮肤菜单、语言 |
| `ToolSidebar`（重写） | 一级分类导航（全部 + 10 个领域分类）、底部主题入口与暗黑开关 |
| `LauncherPanel` | 磁贴分区、分类过滤、搜索结果、收藏视图、空态 |
| `LauncherCard` | 渐变磁贴：图标、中文名、英文名、悬停上浮、收藏星标 |
| `ToolGlyph` | 76 个工具的矢量图标（渐变圆角底 + 白色字形，48 种语义字形） |
| `Skin` | 三档皮肤（暗黑 / 多彩浅色 / 护眼）的配色推导 |
| `MainFrame`（重写） | 顶栏 + 分隔条 + 启动器/工具页切换 + 状态栏 |

`ThemeManager` 增加 `Skin` 概念与「护眼」主题；`Tokens` 增加磁贴尺寸与圆角；
`WorkbenchIcons` 增加太阳、月亮、星标、齿轮、返回、调色板等外壳图标。

## 功能对账

重构不删除任何原有能力，逐项对应如下：

| 原能力 | 新位置 |
|---|---|
| 76 个工具入口 | 「全部工具」分区磁贴，按 10 个分类分区展示 |
| 分类筛选 | 侧栏一级分类 |
| 搜索（名称/英文名/关键词/分类） | 顶栏搜索框，`Ctrl+K` 聚焦 |
| 搜索结果方向键直达 | 搜索框 `↓` 跳到第一张磁贴 |
| 主题切换（50+ FlatLaf 主题） | 齿轮菜单 →「更多主题…」 |
| 语言切换 | 顶栏右侧下拉 |
| 侧栏折叠/展开 | 侧栏头部收起按钮 + 顶栏展开按钮 |
| 侧栏拖动调宽 | 保留 `JSplitPane` |
| 工具视图懒加载与状态保持 | `ToolContentHost` 原样复用 |
| 导航状态持久化 | 继续写 `nav.selectedTool` / `nav.sidebarWidth` / `nav.sidebarCollapsed` |
| 状态栏（就绪/JDK/CPU/内存） | 保留 |
| 窗口尺寸与位置记忆 | 保留 |
| 保险库、SSH 指纹确认等生命周期 | 未改动 |

新增：收藏（持久化）、一键深浅切换、三档皮肤、启动器空态、`Esc` 返回列表。

`nav.expandedGroups` 不再写入——一级导航没有展开状态；旧配置残留不影响启动。

## 主题与皮肤

皮肤决定「磁贴与导航如何从分类品牌色推导」，主题仍决定 LAF：

- `DARK`：品牌色压进 `#151C27`，磁贴接近深色玻璃；
- `LIGHT`：向白色提亮，磁贴是淡彩；
- `EYE_CARE`：色相收敛到 17°~60° 并压低饱和度，底色调到米色，图标改用深琥珀以保证对比。

分类色相固定（安全=靛蓝、编码=天蓝、网络=绿、数据=橙、云原生=蓝……），
同组内按工具 ID 做 ±22° 微偏移，因此一屏有层次但不会失去分组感。

修复了一个启动期缺陷：`setupDefault()` 原先在 `applyCustomDefaults()` 之后才设置皮肤，
导致深色主题套用了浅色色板（深色下卡片标题不可读）。现在皮肤先于色板确定，
并在 `applyCustomDefaults()` 中按实际 LAF 明暗校正，外部直接 `FlatLaf.setup()` 也能正确取色。

## 已知限制

- 长工具名在磁贴上会省略（中英文各留一行），完整名称在 tooltip 与工具页标题里。
- 顶栏标题上限 260px，超出以省略号收尾；这是为了避免长标题把搜索框挤出可视区。
- 护眼模式只改壳层色板，工具面板内部仍是主题颜色，未做逐面板的色温调整。
